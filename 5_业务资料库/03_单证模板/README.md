# 单证模板

> **用途**：存放报关单、发票、装箱单等模板
> **维护部门**：单证部 / 报关部
> **更新频率**：按需更新（税务/海关政策变动时）
> **⚠️ 重要提示**：以下所有文件均为模拟示例数据，仅供格式参考，请勿直接用于正式报关。请在使用前替换为真实业务数据并根据最新海关要求核对。

## 📂 目录说明

| 文件 | 用途 | 更新频率 |
| :--- | :--- | :--- |
| `商业发票模板.md` | 形式发票（PI）、商业发票（CI）格式 | 按需 |
| `装箱单模板.md` | 每票货的包装明细 | 按需 |
| `报关单草稿模板.md` | 预录入报关信息草稿 | 按需 |
