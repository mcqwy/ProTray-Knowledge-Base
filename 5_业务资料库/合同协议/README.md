# 合同协议

> **用途**：存放采购合同、NDA、保密协议等
> **维护部门**：法务 / 销售部 / 采购部
> **更新频率**：按需更新
> **⚠️ 重要提示**：以下所有文件均为模拟示例数据，仅供格式参考，请勿直接用于正式业务。请在使用前替换为真实合同条款并咨询法务确认。

## 📂 目录说明

| 文件 | 用途 | 备注 |
| :--- | :--- | :--- |
| `采购合同模板.md` | 向供应商下单的正式合同模板 | 以真实法律文本为准 |
| `NDA保密协议.md` | 与客户/代理签署的保密协议 | 建议法务审核后使用 |
