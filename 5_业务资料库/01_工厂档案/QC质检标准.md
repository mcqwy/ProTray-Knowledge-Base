# QC 质检标准（模拟示例数据，请勿直接使用）

> **重要提示**：以下所有标准数据（尺寸公差、克重范围等）均为模拟示例，仅供格式参考。请替换为工厂实际执行的质检标准后使用。

## 📋 出货检验标准（AQI）

### 1. 尺寸精度标准

| 参数 | 允许公差 | 检测工具 | 检测频率 |
| :--- | :--- | :--- | :--- |
| 外径（长×宽） | ± 0.5mm | 三坐标测量仪 | 每批次 5 片 |
| 孔深 | ± 0.3mm | 游标卡尺 | 每批次 10 片 |
| 上口径 | ± 0.2mm | 游标卡尺 | 每批次 10 片 |
| 底孔直径 | ± 0.2mm | 游标卡尺 | 每批次 10 片 |
| 克重 | ± 2g | 电子秤 | 每批次 20 片 |
| 翘曲度 | ≤ 1.5mm/500mm | 标准平板 + 塞尺 | 每批次 5 片 |
| 四角高度差 | ≤ 1.0mm | 标准平板 + 塞尺 | 每批次 5 片 |

### 2. 外观标准

| 项目 | 合格标准 | 不合格判定 |
| :--- | :--- | :--- |
| 表面光洁度 | 光滑均匀，无毛刺 | 有毛刺、飞边、流痕 |
| 颜色一致性 | 目视无色差 | 明显色差（超过ΔE 2.0） |
| 气泡/白点 | 每盘 ≤ 3 个直径 < 0.5mm | 超过 3 个或直径 > 0.5mm |
| 变形 | 叠加平放自然回正 | 肉眼可见弯曲或扭曲 |
| 清洁度 | 无油污、无粉尘 | 可见脏污 |

### 3. 机械性能标准

| 项目 | 合格标准 | 测试方法 |
| :--- | :--- | :--- |
| 对折测试（常温） | 180° 对折不出现白痕或断裂 | 随机抽样，手工对折 |
| 低温抗冲击（0°C） | 无脆裂 | 抽样，0°C 冷冻 2 小时后进行 1 米跌落 |
| 堆码承重（单盘） | ≥ 15kg 不变形 | 静态承重测试（平放加载砝码） |
| 悬空承重（540mm 跨度） | 形变 ≤ 2% | 模拟自动化流水线跨度加载 |

## 📝 检验流程

```
┌─────────────────────────────────────────────────────────────────┐
│                   出货质检 SOP                                  │
├─────────────────────────────────────────────────────────────────┤
│ Step 1：来料检验（IQC）                                        │
│ ├── 检查 rPET 原料颜色、气味、含水率                          │
│ └── 合格 → 进入生产，不合格 → 退回                            │
├─────────────────────────────────────────────────────────────────┤
│ Step 2：在线抽检（IPQC）                                       │
│ ├── 开机首检：前 20 片全尺寸检验                              │
│ ├── 生产巡检：每小时抽检 10 片                                │
│ └── 模具有异常时立刻停机调整                                  │
├─────────────────────────────────────────────────────────────────┤
│ Step 3：成品全检（FQC）                                        │
│ ├── 每卡板（约 500 片）抽取 20 片进行全尺寸检验              │
│ ├── 外观：100% 目视检查（流水线人工 + 视觉检测仪辅助）       │
│ └── 每批随机抽取 5 片做破坏性测试（对折 + 承重）              │
├─────────────────────────────────────────────────────────────────┤
│ Step 4：出货检验（OQC）                                        │
│ ├── 每批次抽取 1 卡板全面复检                                 │
│ ├── 生成纸本《出货检验报告》                                  │
│ └── 合格 → 贴合格标签 / 放行发货                              │
└─────────────────────────────────────────────────────────────────┘
```
