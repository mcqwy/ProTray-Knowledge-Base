## 📖 知识库说明

## 📌 常见问题

**Q：为什么主文档不加版本号？**  
A：文件名不加版本号，便于内部引用和文档间互相跳转。版本号统一维护在主文档内部的版本更新记录中。

**Q：新增获客方式怎么加？**  
A：在 `2_获客操作手册/` 目录新建对应的 `.md` 文件 → 在 `外贸获客全景指南.md` 对应大类表格中追加一行 → 更新版本更新记录。

**Q：模板文件怎么用？**  
A：`4_销售百宝箱/` 下的 `.md` 文件都包含使用说明 + 示例数据 + 可直接复制的模板内容，按说明操作即可。

**Q：AI 工具相关文档在哪个目录？**  
A：所有 AI 自动化获客相关内容统一放在 `7_ai工具相关/` 目录下，含工具清单、部署指南、Prompt 模板、CRM 联动方案等。
