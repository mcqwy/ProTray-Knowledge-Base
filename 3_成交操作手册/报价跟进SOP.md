# 报价跟进SOP（标准作业程序）

> **用途**：报价发出后的完整跟进流程，确保每个报价都有节奏地跟踪到底
> 
> **更新日期**：2026-09-05
> 
> **适用对象**：外贸业务员、销售经理
> 
> **所属阶段**：成交转化（样品确认 → 报价 → 跟进 → 签约）


## 📋 核心时间线

| 时间节点 | 动作 | 责任人 | 话术参考 |
| :--- | :--- | :--- | :--- |
| Day 0 | 发送报价单 + 产品规格书 | 业务员 | — |
| Day +3 | 首次跟进（确认收到） | 业务员 | H-001 |
| Day +7 | 二次跟进（补充价值信息） | 业务员 | H-002 |
| Day +14 | 三次跟进（锁定卡点） | 业务员 | H-003 |
| Day +21 | 最后尝试（归档或激活） | 业务员 | H-004 |
| Day +28 | 转入长期培育池 | 业务员 | — |


## 📝 每次跟进前必做检查

| 序号 | 检查项 | 说明 |
| :--- | :--- | :--- |
| 1 | 上次沟通内容回顾 | 翻看邮件/WhatsApp历史记录，确保不重复问同样问题 |
| 2 | 客户背景更新 | 去LinkedIn/官网查看客户是否有新动态（扩张、新产品、融资等） |
| 3 | 竞品动态 | 是否注意到新竞争对手？价格/产品是否有变化？ |
| 4 | 工厂排期 | 确认当前产能情况，以备客户问交期时能即时回复 |


## 📊 跟进状态管理

| 状态 | 定义 | 下一步动作 |
| :--- | :--- | :--- |
| 🔵 **报价中** | Day 0-7，客户暂无明确反馈 | 按时跟进 |
| 🟡 **谈判中** | 客户有回复，正在讨论条款 | 快速响应，每次沟通后24h内回复 |
| 🟢 **已成交** | 已收到PO或定金 | 转入生产交付流程 |
| 🔴 **已丢失** | 客户明确告知已选择其他供应商 | 礼貌收尾，标记归档，录入流失原因 |
| ⚪ **待激活** | Day +21 仍无回复 | 暂停跟进，标记90天后激活 |


## 🔄 异常情况处理

| 异常情况 | 处理方式 |
| :--- | :--- |
| 客户邮件退信 | 通过LinkedIn/WhatsApp/电话主动联系，确认邮箱是否正确 |
| 客户说“正在等上面批复” | 追问：“大概需要多久？我可以到时再跟进” → 在CRM中设置到期提醒 |
| 客户提到已在用竞品 | 不攻击竞品，而是问：“有没有哪些方面您希望有改进空间？” 找到突破口 |
| 客户一直“已读不回” | 参考 H-003 或 H-004，尝试降价试探或主动退出，给客户台阶下 |
