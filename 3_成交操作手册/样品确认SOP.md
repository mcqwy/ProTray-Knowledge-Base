# 样品确认SOP（标准作业程序）

> **用途**：从客户同意寄样到样品确认、最终促成订单的全流程
> 
> **更新日期**：2026-09-05
> 
> **适用对象**：外贸业务员、跟单员
> 
> **所属阶段**：成交转化（初次沟通 → 样品确认 → 报价）


## 🔗 本环节在全链条中的位置

**全链条**：市场调研 → 获客 → 初次沟通 → 样品确认 → 报价 → 谈判 → 签约 → 交付

**当前环节**：⬆️ 样品确认（本文件）


## 📋 寄样前必做清单

| 序号 | 动作 | 说明 |
| :--- | :--- | :--- |
| 1 | 确认客户是否为决策人 | 如是采购助理，需同步让其抄送决策人 |
| 2 | 明确寄样目的 | 是用于：外观确认？功能测试？机械手适配验证？ |
| 3 | 确认样品参数 | 客户要求的尺寸、材质、颜色是否明确 |
| 4 | 确认运费承担方 | 建议新客户首次样品免样品费，收运费；老客户可全免 |
| 5 | 确认寄样地址 | 地址、邮编、收件人、电话四项必须完整 |


## 📧 样品前沟通话术

### 确认寄样细节

**Subject**: Sample arrangement - [Product Name] to [Company]

```
Hi [Name],

Great! We'll arrange the sample accordingly.

Before we ship, could you please confirm:
1. The shipping address (full details)
2. Your preferred courier (DHL / FedEx / UPS — we usually use DHL, takes 3-5 days)
3. Shall we proceed with a free sample + freight collect, or do you prefer we handle shipping?

Will send you the tracking number once dispatched.

Best regards,
[Your Name]
[Your Title]
[WhatsApp/Phone]
```


## 📦 寄样执行

### Step 1：样品准备

| 检查项 | 说明 |
| :--- | :--- |
| 样品数量 | 通常 2-5 片（一片用于测试，其余留作对比） |
| 标识 | 贴标签标注：材质、克重、孔数、生产日期 |
| 附带资料 | 产品规格书 + 样品确认单 |
| 包装 | 确保运输途中不损坏（泡棉/气泡膜加固） |

### Step 2：发出后通知

```
Subject: Tracking number for sample shipment - [Order/Ref No.]

Hi [Name],

Just a quick update: your sample has been dispatched via [Courier Name]. The tracking number is [XXXXX].

You can track it here: [link]

Estimated delivery: [date]

Please let me know when it arrives, and I'll share a quick checklist for evaluation.

Best regards,
[Your Name]
[Your Title]
[WhatsApp/Phone]
```


## 📞 样品到达后跟进

### 时间线

| 时间节点 | 动作 | 话术 |
| :--- | :--- | :--- |
| 签收当天 | 确认收到 | “I see your sample was delivered today. Hope everything arrived safely!” |
| 签收 + 2 天 | 询问初步印象 | “Have you had a chance to take a look at the sample yet?” |
| 签收 + 5 天 | 测试结果询问 | “Any preliminary feedback from the testing team?” |
| 签收 + 10 天 | 促成下单 | “We have this material in stock. If you're satisfied, we can proceed with production within 48 hours.” |

### 样品跟进话术模板

**第一天（签收当天）**：

```
Hi [Name], tracking shows your sample arrived today. Hope everything is in good condition. Let me know if you have any questions when you check it.
```

**第三天（初步印象）**：

```
Hi [Name], just checking in — have you had a chance to review the sample? Any initial thoughts?
```

**第七天（测试跟进）**：

```
Hi [Name], quick follow-up — have you done any testing on the sample? We're happy to provide additional technical data if needed for the evaluation process.
```

**第十四天（促成下单）**：

```
Hi [Name], since you've had the sample for a couple of weeks now, I wanted to check in — what are your thoughts? If you're satisfied with the quality, we can proceed with production right away. Our current lead time is [XX] days.
```


## 📊 样品状态管理

| 状态 | 定义 | 下一步动作 |
| :--- | :--- | :--- |
| 🟡 **待寄出** | 已确认寄样，尚未发货 | 2个工作日内安排寄出 |
| 🟡 **运输中** | 已发出，尚未送达 | 每2天查看一次物流状态 |
| 🔵 **已送达** | 客户已签收 | 当天发送确认消息，+2天跟进 |
| 🟢 **测试中** | 客户已开始测试 | 每3-5天跟进一次测试进展 |
| 🔴 **已失败** | 客户测试不通过 | 询问原因，记录反馈，判断是否值得改进重寄 |
| ✅ **已通过** | 客户确认样品合格 | 立即跟进报价 + 促单 |


## 🔄 常见异常与应对

| 异常情况 | 处理方式 |
| :--- | :--- |
| 样品签收后客户一直不回复 | 参考话术：先问测试进展，再不回复则发“是否还需要我这边继续跟进？” |
| 样品运输损坏 | 第一时间补发，附道歉说明，运费由我方承担 |
| 样品测试不合格（客户指出具体问题） | 评估是否可改进，可改进则重做重寄，不可改进则说明原因 |
| 客户说“样品质量没问题但价格贵” | 这时候才真正进入报价谈判阶段 → 参考报价与成交指南 |
