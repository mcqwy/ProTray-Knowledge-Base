# 初次沟通SOP（标准作业程序）

> **用途**：从获客到首次正式沟通的全流程指南，帮助业务员建立专业第一印象
> 
> **更新日期**：2026-09-05
> 
> **适用对象**：外贸业务员、新入职销售
> 
> **所属阶段**：成交转化（从线索到成交的第一步）


## 🔗 本环节在全链条中的位置

**全链条**：市场调研 → 获客 → 初次沟通 → 样品确认 → 报价 → 谈判 → 签约 → 交付

**当前环节**：⬆️ 初次沟通（本文件）


## 📋 沟通前准备（Pre-Call Checklist）

| 序号 | 准备项 | 具体内容 | 工具/来源 |
| :--- | :--- | :--- | :--- |
| 1 | 公司背调 | 官网、LinkedIn公司页、Google新闻 | 搜索 + LinkedIn |
| 2 | 决策人背景 | 职位、任职时间、过往经历 | LinkedIn个人页 |
| 3 | 客户痛点预判 | 他可能在找什么？价格？质量？新供应商替代？ | 通过官网产品定位 + 海关数据分析 |
| 4 | 我方切入点 | 一句话说清楚：为什么他要回复我？ | 差异化卖点提炼 |


## 💬 首次触达方式选择

| 场景 | 推荐方式 | 原因 |
| :--- | :--- | :--- |
| 海关数据获取的客户 | 邮件 + LinkedIn双重触达 | 海关数据只有公司名，需多触点覆盖 |
| LinkedIn Profile 完整 | LinkedIn InMail（付费版）或加好友发消息 | 决策人本人活跃在平台上 |
| 展会名片获取 | WhatsApp 优先，邮件为辅 | 已有初步印象，WhatsApp更直接 |
| 黄页/名录获取 | 邮件为主 | 没有其他可靠联系方式 |


## 📧 首次触达邮件模板

### 模板A：简洁专业型（适用于海关数据/名录客户）

**Subject**: [Product] supply for [Target Market] - [Your Company]

```
Hi [Name],

I noticed [Company Name] imports [Product] from [Country/Region].

We are a [Country]-based manufacturer with [X] years of experience in [Product]. We've worked with clients in [similar market/industry] and helped them [specific benefit, e.g., reduce cost by 15% / improve durability].

Would you be open to a brief 5-minute call next week? I'd love to learn more about your current sourcing needs.

Best regards,
[Your Name]
[Your Title]
[WhatsApp/Phone]
```

### 模板B：展会后破冰（适用于展会名片客户）

**Subject**: Great meeting you at [Exhibition Name]

```
Hi [Name],

It was a pleasure meeting you at [Exhibition] last week. I recall you mentioned [specific pain point/interest].

Just to follow up — our [Product] has been well received in [country/market] for [specific reason]. I'd be happy to send you more details or a free sample for evaluation.

Let me know what works best for you.

Best regards,
[Your Name]
[Your Title]
[WhatsApp/Phone]
```


## 📞 首次电话/WhatsApp沟通脚本

### 开场白（30秒内）

```
Hi [Name], this is [Your Name] from [Your Company]. Hope I'm not catching you at a bad time.

I saw [Company Name] from [source, e.g., LinkedIn / directory / exhibition]. I noticed you're in the [industry] space.

Quick question — do you currently source [Product] from overseas suppliers, or do you work locally?
```

### 如果客户说“我没时间”

```
Understood — would it be okay if I send you a brief email with some details? You can read it whenever you have time.
```

### 如果客户说“我们已经有供应商了”

```
That's great! It shows you already have a solid supply chain. Quick follow-up — is there any area you wish your current supplier could improve on? (e.g., delivery time, quality consistency, pricing?)
```

### 结束语（无论结果如何）

```
Thanks for your time, [Name]. I'll send over a short summary of what we discussed. Have a great day!
```


## 📝 沟通后必做清单

| 步骤 | 动作 | 时间要求 |
| :--- | :--- | :--- |
| 1 | 在客户跟进表中记录沟通摘要 | 沟通结束后 30 分钟内 |
| 2 | 标记意向等级（A/B/C） | 同上 |
| 3 | 发送书面跟进（感谢 + 补充信息） | 沟通结束后 24 小时内 |
| 4 | 设置下次跟进提醒 | 同上 |


## 📊 客户意向等级快速判定

| 等级 | 判断标准 | 跟进策略 |
| :--- | :--- | :--- |
| A（高） | 客户主动询问价格、MOQ、交期，或要求寄样 | 48小时内出报价，优先跟进 |
| B（中） | 客户回复了但较简短，或表现出基础兴趣 | 3天内提供价值信息（如产品册、案例） |
| C（低） | 已读不回，或明确说“暂时不需要” | 加入培育池，30天后再次触达 |
