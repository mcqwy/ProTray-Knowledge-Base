## 一、AI 获客与线索挖掘类

### 1. AI_Find_Customer（AI Hunter）

| 属性 | 内容 |
| :--- | :--- |
| **定位** | 面向外贸与B2B场景的AI客户挖掘系统 |
| **核心架构** | FastAPI + LangGraph + React 多Agent流水线 |
| **开源仓库** | https://github.com/xiongQvQ/AI_Find_Customer |
| **官网** | https://b2binsights.io/ |
| **演示视频** | https://www.bilibili.com/video/BV1AzwYzXEGD/ |
| **开源协议** | 未明确标注（部分模块闭源） |
| **费用** | 开源版免费自部署；B2Binsights 商业版一次性收费 |
| **试用方式** | 加微信 **XiongX0110**，免费试跑一批线索样本 |
| **搜索/爬虫方式** | Google Search + Google Maps + B2B平台站内搜索 + 自适应网页抓取 |
| **聊天回复支持** | ✅ 邮件（AI生成回复草稿，人工审批后发送） |

**核心能力**：
- 自动闭环流水线：`Insight → KeywordGen → Search → LeadExtract → Evaluate`
- 多搜索通道：Google Search + Google Maps + B2B平台站内
- 自动提取邮箱、电话、地址、社媒链接等结构化信息
- 双模型协作：推理模型负责ReAct决策，普通模型负责抽取与生成
- AI生成3步开发信序列，支持预览、审批、campaign自动发送
- **扫描收件箱识别客户回复，发现回复后停止自动化，转交真人处理**

**人工介入时机**：发送前人工审核；客户回复后停止自动化，交由真人处理

**风险等级**：🟡 常规爬虫风险（建议配合代理IP池使用）


### 2. b2b-buyer-discovery

| 属性 | 内容 |
| :--- | :--- |
| **定位** | 专为外贸人打造的AI获客工具 |
| **核心架构** | Node.js |
| **开源仓库** | https://github.com/Tommy-old/b2b-buyer-discovery |
| **开源协议** | 未明确标注 |
| **费用** | 免费（需自备 SerpAPI 等密钥） |
| **试用方式** | 零门槛试用，无需信用卡 |
| **搜索/爬虫方式** | Google批量搜索，自动抓取搜索结果页，提取公司名、邮箱、电话、WhatsApp |
| **聊天回复支持** | ❌ 无（仅生成开发信，不含发送及自动回复功能） |

**核心能力**：
- 多关键词 × 多市场批量搜索
- AI双层评分：规则引擎 + AI深度分析购买意向
- 自动提取邮箱、电话、WhatsApp
- 12分制意向评分，按极高/高/中/低排序
- 西英双语开发信自动生成（拉美市场自动用西班牙语）
- 一键导出CSV，含WhatsApp直链、LinkedIn搜索链接

**人工介入时机**：生成开发信后，需人工复制内容并通过自己的邮箱发送，后续跟进完全由真人负责

**风险等级**：🟡 常规爬虫风险


## 二、全链路 AI 销售代理类

### 3. B-agent

| 属性 | 内容 |
| :--- | :--- |
| **定位** | 外贸B端全链路AI自动化获客转化Agent系统 |
| **开源仓库** | https://github.com/EricHong123/B-agent |
| **开源协议** | 未明确标注 |
| **费用** | 免费自托管 |
| **试用方式** | 自行部署测试 |
| **搜索/爬虫方式** | Hunter.io域名搜索、联系人查找和验证、批量富化任务 |
| **聊天回复支持** | ✅ 邮件（Gmail/Outlook集成，分阶段人工审批） |

**核心能力**：
- 智能获客：域名搜索、指定联系人、批量补全、联系人验证、ICP评分
- 三层记忆底座：working、session、long-term
- 企业RAG底座：知识文档版本、组织命名空间、ACL后置复核
- AI路由控制：支持直连供应商或OmniRoute统一路由
- 人工审批投递：调研、文案和发送分阶段审批
- 邮箱连接：Gmail与Microsoft OAuth

**人工介入时机**：调研、文案、发送每个阶段都需要人工审批，发送前再次校验联系人、ICP等

**风险等级**：🟡 依赖第三方API（Hunter.io），有调用限额


### 4. OpenOutreach（双版本）

**共同定位**：自托管、开源的AI销售代理

#### 4.1 Email版

| 属性 | 内容 |
| :--- | :--- |
| **开源仓库** | https://github.com/eracle/OpenOutreach |
| **开源协议** | **GPL-3.0** |
| **费用** | 免费（自带 LLM API Key） |
| **试用方式** | 一条命令运行：`uv tool install openoutreach` |
| **搜索/爬虫方式** | ❌ **零爬取**。使用**授权数据提供商**获取匹配的潜在客户 |
| **聊天回复支持** | ✅ 邮件（**全自动AI代理**，自主完成从发信到多轮跟进的完整流程） |

**核心能力**：
- 自主发现线索：描述产品和目标市场，AI自动发现潜在客户
- ICP筛选：LLM将产品描述转为ICP过滤器
- 贝叶斯评分：高斯过程回归器对画像进行评分
- 智能邮件：AI代理发送个性化邮件并管理多轮跟进
- **AI读取回复并执行多轮跟进，直到达成明确结果或AI判断无法继续**
- 零平台风险：无浏览器、无社交账号、无爬取

**人工介入时机**：仅在AI无法处理或需要最终确认时介入，设计上追求最大化自动化

**风险等级**：🟢 **零风险（无爬虫）**

#### 4.2 LinkedIn版

| 属性 | 内容 |
| :--- | :--- |
| **开源仓库** | https://github.com/cipriantepes/OpenOutreach |
| **开源协议** | **AGPL** |
| **费用** | 自托管免费；云版（OpenOutreach Cloud）付费 |
| **试用方式** | Docker 一键部署，含交互式引导 |
| **搜索/爬虫方式** | ✅ Playwright + 隐身插件模拟真人浏览LinkedIn |
| **聊天回复支持** | ✅ LinkedIn私信（AI管理对话流程，自主决定发送、等待或结束对话） |

**核心能力**：
- AI自动生成LinkedIn搜索查询
- 贝叶斯ML模型学习匹配理想客户
- Playwright + 隐身插件模拟真实用户行为
- AI代理管理多轮跟进对话

**人工介入时机**：当AI判断对话已达成明确结果（如客户已转化、不感兴趣等）时任务结束，过程中主要依赖AI驱动

**风险等级**：🔴 **高风险（模拟真人）** — LinkedIn有封号风险，慎用


## 三、一体化外贸工作台类

### 5. TradeOS（铲子）

| 属性 | 内容 |
| :--- | :--- |
| **定位** | 外贸客户发现与销售执行系统 |
| **核心架构** | FastAPI + SQLAlchemy + MySQL + Vue 3 |
| **开源仓库** | https://github.com/wslyb/-TradeOS |
| **开源协议** | Apache-2.0（v0.1.0）；后续版本“源码开放、企业内部免费使用” |
| **费用** | 企业内部免费使用 |
| **试用方式** | Docker Compose 一键启动 |
| **搜索/爬虫方式** | 官网搜索与抓取；支持 Bright Data、Apify、DataForSEO 等第三方服务 |
| **聊天回复支持** | ✅ 邮件、WhatsApp、LinkedIn（营销话术Agent生成各渠道话术，人工审核后发送） |

**核心能力**：
- **客户发现**：根据产品、目标国家和买家类型生成搜索策略
- **企业大脑**：统一管理企业资料、产品、目标市场、客户画像
- **营销话术Agent**：生成开发邮件、WhatsApp、LinkedIn、展会邀约话术
- **客户资产中台**：客户发现完成后自动落库
- **CRM客户池**：记录开发阶段、负责人、互动记录
- **开发任务与邮件**：生成、审核、发送并追踪外贸开发任务

**人工介入时机**：发送前通常需要人工审核话术内容

**风险等级**：🟡 常规爬虫风险；可选用付费商业爬虫服务（更稳定）


## 四、外贸 CRM 与业务管理类

### 6. TradePilot（开源版）

| 属性 | 内容 |
| :--- | :--- |
| **定位** | 开源AI外贸CRM与订单履约工作台，面向1-5人外贸团队 |
| **核心架构** | 支持Docker自托管和源码级扩展 |
| **开源仓库** | https://github.com/feifei9126/tradepilot |
| **在线演示** | https://tradepilot.us.kg/（测试账号 `admin@admin.com` / 密码 `12345678`） |
| **开源协议** | **AGPL-3.0** |
| **费用** | 免费自托管 |
| **试用方式** | 在线演示可用 / Docker一键部署 |
| **搜索/爬虫方式** | **Firecrawl产品采集**：从公开产品页提取名称、描述、规格、图片和视频 |
| **聊天回复支持** | ✅ 邮件、WhatsApp（AI生成草稿/选项，用户手动确认后发送） |

**核心能力**：

**外贸CRM与订单履约**：
- 客户档案、联系人、标签、来源与跟进状态
- 询盘创建、状态流转和AI回复草稿
- 报价草稿、贸易术语、成本加价与人工接受确认
- 报价转订单、订单进度、沟通记录和交期风险
- 出货、物流、供应商、财务汇总与单证草稿
- 仪表盘、销售漏斗和待办提醒

**AI模型支持**：
- 支持OpenAI、DeepSeek、通义千问与OpenAI兼容服务
- 支持Ollama本地模型（推荐模型和安装命令）
- API Key保存在当前浏览器，通过服务端发起请求

**邮件与WhatsApp的AI支持**：
- **邮件**：AI生成回复草稿，支持多语言邮件解析，在审批队列中人工确认“接受”或“拒绝”后才发送
- **WhatsApp**：通过Chrome插件分析对话并生成三种回复选项供用户选择，用户点击后自动填入输入框，手动点击发送

**产品采集与视频工作流**：
- Firecrawl产品采集：从公开产品页提取产品信息
- FFmpeg Worker：本地快速生成MP4
- MoneyPrinterTurbo：AI自动成片（配音、字幕、音乐）
- OpenMontage：高级制作流水线适配器

**人工介入时机**：邮件需在审批队列中确认后才发送；WhatsApp生成选项后需用户手动点击发送

**风险等级**：🟡 常规爬虫风险（产品采集，非客户挖掘）
