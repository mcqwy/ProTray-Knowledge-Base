# 外贸AI Prompt模板库（即复制即用）

> **版本**：1.0
> 
> **更新日期**：2026-09-05
> 
> **适用对象**：外贸业务员、销售经理、市场人员
> 
> **核心目标**：提供外贸全场景可直接复制使用的 AI Prompt 模板，降低使用门槛，提升工作效率


## 📌 使用说明

| 要点 | 说明 |
| :--- | :--- |
| **怎么用** | 复制内容，粘贴到 ChatGPT / Claude / DeepSeek 等 AI 工具，替换 `[ ]` 中的占位符即可 |
| **占位符说明** | `[产品]`、`[客户名称]`、`[行业]` 等需要你替换为实际内容 |
| **多语言支持** | 部分模板支持中英文双语，可根据客户语言选择 |
| **迭代优化** | 用完后把好的回复存下来，形成团队模板库 |

## 1. 开发信生成类

### 1.1 标准开发信生成

**适用场景**：海关数据 / 黄页 / 名录获取客户后的首次触达

**Prompt 模板**：

```
你是一名资深外贸营销专家。请根据以下信息撰写一封专业的英文外贸开发信：

产品：[产品名称，如：塑料育苗盘]
产品卖点：[卖点1]、[卖点2]、[卖点3]
目标客户：[客户名称/客户类型]
目标市场：[国家/地区]
差异化优势：[与竞品的核心差异]
语言风格：[专业/简洁/亲切]

要求：
1. 主题行（Subject Line）要有吸引力
2. 正文：简洁、专业、非推销感
3. 突出客户的潜在利益，而非产品功能
4. 包含明确的行动指令（Call to Action）
5. 控制在 5-8 句话以内

请提供 2 个版本：版本A（正式商务版）、版本B（简洁亲切版）
```

**示例输出**（假设产品为育苗盘）：

| 版本 | 适用场景 | 特点 |
| :--- | :--- | :--- |
| 版本A | 大型企业、欧洲客户 | 正式、数据支撑、长一些 |
| 版本B | 中小企业、美国客户 | 简洁、口语化、直接 |


### 1.2 差异化开发信生成（客户有现有供应商）

**适用场景**：已知客户已有固定供应商，需要找到突破口

**Prompt 模板**：

```
我准备联系一家已有固定供应商的潜在客户。请帮我写一封差异化开发信，重点突出"换供应商的理由"。

客户信息：
- 客户名称：[名称]
- 客户行业：[行业]
- 现有供应商所在地：[如：越南/宁波]
- 我了解到的痛点：[如果有，如：听说他们交期不稳定]

我方优势：
- [优势1，如：交期比同行快30%]
- [优势2，如：材质更耐用]
- [优势3，如：支持小批量定制]

要求：
1. 不要攻击竞品
2. 用"提供备选方案"的角度切入
3. 语气温和，给客户台阶
4. 包含一个低风险的"试单"提议（如样品单）

请写一封英文开发信，并附上中文翻译供内部参考。
```


### 1.3 展会后续跟进开发信

**适用场景**：展会见面后的二次跟进

**Prompt 模板**：

```
我在[展会名称]上遇到了[客户名称]的[联系人姓名]，当时聊到了[产品/话题]。

请帮我写一封跟进邮件：
1. 提及我们是在展会上认识的
2. 回顾当时聊到的具体内容（[具体内容]）
3. 补充当时没有提供的信息（[补充信息]）
4. 提议下一步动作（如寄样、电话会议等）

语气：[专业/亲切]
邮件语言：[英文/中英双语]
```


## 2. 客户回复分析类

### 2.1 客户回复意图分析

**适用场景**：客户回复了邮件，但不清楚对方真实意图

**Prompt 模板**：

```
以下是客户回复的邮件内容：

[粘贴客户邮件全文]

请帮我分析：
1. 客户的真实意图是什么？（想购买/还在比价/只是礼貌回复/暂时不需要？）
2. 客户的决策阶段是什么？（意识问题/考虑方案/评估供应商/准备购买？）
3. 客户的隐藏需求或顾虑可能是什么？
4. 我应该如何回复？请给出回复建议框架
   ```


### 2.2 客户冷淡回复的应对策略

**适用场景**：客户只回了"Thanks, we'll review it."或类似简短回复

**Prompt 模板**：

```
客户回复了以下内容，比较简短/冷淡：

[粘贴客户回复]

背景信息：
- 我发的邮件：[简述你发了什么]
- 产品：[产品]
- 之前的互动：[如有]

请帮我：
1. 分析客户可能的真实想法
2. 给出 3 种不同策略的回复方案：
    - 方案A：继续培养（温和跟进）
    - 方案B：直接询问（锁定卡点）
    - 方案C：提供价值（发送有用资料）
3. 推荐其中一种，并说明理由
   ```


## 3. 报价谈判类

### 3.1 模拟客户谈判（价格谈判）

**适用场景**：新人练习谈判技巧，或准备客户谈判话术

**Prompt 模板**：

```
请扮演一名[国家]的[客户类型]，和我进行价格谈判演练。

你的角色设定：
- 性格：[谨慎/冲动/保守/激进]
- 风格：[喜欢直接谈价格/喜欢先聊关系/喜欢对比多家]
- 你的目标：压价 10%，否则可能选择其他供应商

我的产品：
- 名称：[产品]
- 报价：[价格]
- 成本底线：[最低可接受价格]
- 核心卖点：[为什么值这个价]

请开始扮演客户，我会回复你。一轮一轮地谈，直到成交或谈崩。
```


### 3.2 客户"太贵了"的应对策略

**适用场景**：客户说"太贵了"，需要准备应对话术

**Prompt 模板**：

```
客户说我的报价太贵了。背景信息：

客户：[客户名称/类型]
产品：[产品]
我的报价：[价格]
竞品报价：[如知道，填写]
客户说太贵了的具体上下文：[如：客户说"比我现在供应商贵20%"]

请帮我：
1. 分析客户可能是在真觉得贵，还是习惯性压价
2. 给出 3 种不同的回应策略：
    - 策略A：强调价值（品质、交期、服务）
    - 策略B：试探客户真实价格预期
    - 策略C：提供替代方案（降配、减量）
3. 每种策略给出具体话术（英文版 + 中文翻译）
   ```


### 3.3 报价跟进话术生成

**适用场景**：报价发出后，在不同时间节点跟进客户

**Prompt 模板**：

```
我于[日期]向[客户名称]发送了报价单（报价编号：[编号]），报价内容如下：

[简述报价内容]

截止今天，客户还没有回复。现在是报价后的第[天数]天。

请帮我生成一封跟进邮件：
- 跟进节奏：[首次跟进/二次跟进/三次跟进/最后尝试]
- 语气：[温和/紧迫/从容]
- 核心目的：[确认收到/询问意向/补充信息/制造紧迫感]

要求：不要只问"您考虑好了吗"，要提供新信息或新价值。
```


## 4. 邮件优化类

### 4.1 邮件标题优化

**适用场景**：开发信打开率低，需要优化主题行

**Prompt 模板**：

```
我正在写一封发给[客户类型]的开发信，主题行暂定为：

[当前主题行]

产品：[产品]
目标市场：[国家]
客户痛点：[如知道]

请帮我：
1. 评估当前主题行的打开率潜力（1-10分）
2. 提供 5 个替代主题行方案，包括：
    - 1个好奇型
    - 1个利益型
    - 1个数字型
    - 1个个性化型
    - 1个短句型
3. 推荐最有可能打开的 1 个，并说明理由
   ```


### 4.2 邮件语气优化

**适用场景**：邮件太生硬或太随意，需要调整语气

**Prompt 模板**：

```
以下是我写的一封邮件，请帮我优化语气：

[粘贴邮件全文]

目标客户：[客户类型/国家]
期望语气：[更专业/更亲切/更简洁/更有说服力]
关键信息：[必须保留的内容点]

请提供：
1. 优化后的邮件全文
2. 列出做了哪些改动以及为什么
   ```


### 4.3 邮件长度精简

**适用场景**：邮件太长，客户可能没耐心看完

**Prompt 模板**：

```
以下是一封邮件，请帮我精简：

[粘贴邮件全文]

约束条件：
- 保持关键信息完整
- 语气不变
- 将邮件压缩到 5 句话以内
- 每个句子都要有价值

请输出精简后的版本，并标出删除了哪些内容。
```


## 5. 市场调研类

### 5.1 目标市场初步评估

**适用场景**：进入新市场前的快速调研

**Prompt 模板**：

```
我想进入[国家]市场的[产品]领域。请帮我做一个初步市场评估：

产品：[产品名称]
HS编码：[如有]
目标市场：[国家]

请分析：
1. 这个国家的市场规模和增长趋势（5分制评分）
2. 主要竞争对手（至少3家）
3. 市场进入门槛（认证、法规、渠道）
4. 目标客户画像
5. 推荐的进入策略
6. 综合评分和进入建议（建议进入/谨慎进入/暂缓）

请以表格形式呈现核心结论，数据需标明来源。
```


### 5.2 竞品快速分析

**适用场景**：快速了解一个竞品

**Prompt 模板**：

```
请分析以下竞品公司：

公司名称：[竞品名称]
公司网址：[网址]
我的产品：[产品]
我的市场：[目标市场]

请分析：
1. 该竞品的核心产品/服务
2. 该竞品的差异化卖点
3. 该竞品的定价策略（如果公开）
4. 该竞品的优劣势（SWOT简要分析）
5. 他们最可能抢走我的哪类客户
6. 我的应对建议
   ```


### 5.3 客户画像生成

**适用场景**：基于已成交客户数据，提炼理想客户画像

**Prompt 模板**：

```
以下是我过去[时间段]成交的客户数据，请帮我提炼理想客户画像（ICP）：

[粘贴客户数据，至少5个客户]

请分析：
1. 成交客户的共同特征（行业、规模、地区、职位）
2. 成交客户的共同需求/痛点
3. 哪个特征的客户成交转化率最高？
4. 基于分析，生成一份完整的 ICP 描述
5. 建议我应该重点开发的目标客户类型

输出格式：
- 第一部分：数据洞察（关键发现）
- 第二部分：ICP 描述（按维度）
- 第三部分：行动建议
  ```


## 6. 售后跟进类

### 6.1 客诉处理邮件

**适用场景**：客户投诉时，需要写一封专业、得体的回复

**Prompt 模板**：

```
客户投诉了以下问题：

[描述客户投诉内容]

背景信息：
- 客户：[客户名称]
- 产品：[产品]
- 订单编号：[如有]
- 问题严重程度：[轻微/中等/严重]

请帮我写一封客诉回复邮件：
1. 第一段：致歉 + 共情（不要找借口）
2. 第二段：说明调查进展
3. 第三段：提出解决方案（[方案选项]）
4. 第四段：承诺和改进措施

要求：
- 语气诚恳
- 不要推卸责任
- 给客户选择的余地
- 语言：[英文/中英双语]
  ```


### 6.2 复购激活邮件

**适用场景**：客户长时间未下单，需要主动激活

**Prompt 模板**：

```
以下客户上次下单后已经[天数]天没有联系了：

客户：[客户名称]
上次采购产品：[产品]
上次采购量：[数量]
上次成交金额：[金额]
上次沟通记录：[如果有]

请帮我写一封复购激活邮件：
1. 不要直接问"要不要补货"
2. 先提供价值（行业资讯/新品/优惠）
3. 制造合适的紧迫感
4. 给客户一个回复的理由

邮件语言：[英文/中英双语]
```


### 6.3 客户满意度回访问卷

**适用场景**：大客户/长期合作客户的定期满意度调研

**Prompt 模板**：

```
我想给客户发一份简短的满意度回访问卷。客户信息：

客户：[客户名称]
合作年限：[X年]
采购产品：[产品]

请帮我生成一份问卷：
1. 3-5 个核心问题
2. 使用 1-10 评分制 + 1个开放问题
3. 语气亲切，不要像正式调查
4. 简短，2分钟能填完

同时提供邮件正文，用于发送问卷。
邮件语言：[英文/中英双语]
```
