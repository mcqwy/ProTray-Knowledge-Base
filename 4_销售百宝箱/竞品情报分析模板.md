## 📝 使用说明

### 分析维度与数据来源

| 维度 | 数据来源 | 分析价值 |
| :--- | :--- | :--- |
| 获客方式 | SimilarWeb流量分析、搜索竞争对手品牌名看广告、浏览其社媒主页 | 判断对手主要依赖什么渠道获取客户 |
| 谷歌广告投放 | Google搜索对手产品关键词，看广告出现频率和覆盖关键词数量 | 评估对手广告预算和关键词策略 |
| LinkedIn员工数 | 对手LinkedIn公司主页，查看员工数量及岗位分布（销售 vs 市场） | 判断其团队规模与人员配置 |
| 招聘岗位线索 | BOSS直聘、LinkedIn招聘板块、猎聘网 | ⭐ 最有价值！暴露对手下一步战略方向 |

### 使用建议

| 周期 | 操作内容 |
| :--- | :--- |
| 每月 | 更新"招聘岗位线索"，这是洞察对手战略的最佳窗口 |
| 每季度 | 复盘全部数据，识别模式变化，调整"我们的应对策略" |
| 每次策略调整后 | 将"我们的应对策略"在团队会议中讨论确认后执行，并记录执行结果 |
