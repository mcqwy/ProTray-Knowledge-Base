## 📝 使用说明

### 跟进状态选项

| 状态 | 含义 |
| :--- | :--- |
| 待开发 | 已获取联系方式，尚未首次联系 |
| 已发邮件 | 已发送首封开发信，等待回复 |
| 已回复 | 客户已回复邮件，建立初步沟通 |
| 已报价 | 已向客户发送正式报价单 |
| 已寄样 | 已向客户寄送产品样品 |
| 已成交 | 已成功转化为订单客户 |
| 已放弃 | 多次跟进无回应，暂时搁置 |

### 意向等级标准

| 等级 | 判断标准 |
| :--- | :--- |
| A（高） | 3个月内成交概率高，有明确需求，正在报价/寄样阶段 |
| B（中） | 6个月内可能成交，有初步兴趣，需持续培育 |
| C（低） | 长期培育对象，暂无明显意向 |

### 跟进节奏建议

| 客户等级 | 跟进频率 |
| :--- | :--- |
| A级 | 每周至少1次 |
| B级 | 每2周1次 |
| C级 | 每月1次 |

### 日常操作流程

1. 每周一检查"下次跟进日期"为当周的所有客户
2. 每次跟进后立即更新"最近跟进日期"和"跟进状态"
3. 客户状态变化时及时更新"意向等级"
4. 每月末统计各渠道转化率，优化开发策略
