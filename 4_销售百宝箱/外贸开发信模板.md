## 📝 使用说明

| 操作项 | 说明 |
| :--- | :--- |
| 使用次数 | 业务员每次使用该模板后，在"使用次数"列 +1 |
| 回复率 | 回复数 ÷ 使用次数 × 100%，自动计算填入 |
| 定期复盘 | 每月末对比各模板回复率，淘汰低于 3% 的模板，优化高频模板文案 |
| 优化日期 | 每次优化模板内容后，更新"最后优化日期"列 |
