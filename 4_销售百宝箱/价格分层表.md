## 📈 价格分层逻辑（供定价参考）

| MOQ 档位 | 适用场景 | 利润空间 |
| :--- | :--- | :--- |
| 500片 | 新客户试单 | 较高（单件利润最大） |
| 1,000片 | 中小客户常规单 | 中等 |
| 3,000片 | 标准批发量 | 中等偏低 |
| 5,000片 | 大客户订单 | 偏低（走量为主） |
| 10,000片 | 战略客户/年度框架 | 薄利（锁定长期合作） |

> **原则**：每一档之间价差建议在 **5%-10%** 之间，不要跳档太大，避免客户“非最低价不买”。
