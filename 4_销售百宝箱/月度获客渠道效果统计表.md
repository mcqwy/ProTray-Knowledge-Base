## 📝 使用说明

### 关键指标计算公式

| 指标 | 公式 | 说明 |
| :--- | :--- | :--- |
| 获客成本 | 投入成本 ÷ 获客数量 | 每获取一条潜在客户线索的平均成本 |
| 询盘转化率 | 成交订单数 ÷ 有效询盘数 × 100% | 从询盘到成交的转化效率 |
| ROI（投资回报率） | 成交金额 ÷ 投入成本 | 每投入1元带来的销售额倍数 |

### 渠道健康度评估标准

| 指标 | 健康范围 | 需优化 | 建议淘汰 |
| :--- | :--- | :--- | :--- |
| 获客成本 | < 300 元/条 | 300-600 元/条 | > 600 元/条 |
| 询盘转化率 | > 20% | 10%-20% | < 10% |
| ROI | > 3倍 | 1-3倍 | < 1倍 |

### 日常操作流程

| 时间节点 | 操作内容 |
| :--- | :--- |
| 每月 5 日前 | 完成上月数据汇总，填入表格 |
| 每月 5-10 日 | 分析数据，识别高ROI渠道和低效渠道 |
| 连续 2 个月不达标 | 标记为"观察" |
| 连续 3 个月不达标 | 暂停该渠道投放 |
| 高 ROI 渠道 | 考虑加大预算投入 |
