# 大客户管理指南（Key Account Management）

> **用途**：系统性识别、管理、维护公司最有价值的 20% 客户，最大化客户生命周期价值
> 
> **更新日期**：2026-09-05
> 
> **适用对象**：销售经理、大客户经理、外贸负责人
> 
> **所属阶段**：成交转化 → 复购与客户关系深化


## 🔗 本指南在全链条中的位置

**全链条**：市场调研 → 获客 → 初次沟通 → 样品确认 → 报价 → 谈判 → 签约 → 交付 → 收款 → 售后 → 大客户管理 → 持续复购


## 📋 什么是大客户？

| 判断维度 | 标准（满足任一） |
| :--- | :--- |
| 年采购额 | 占公司年营收 ≥ 5% 的客户 |
| 累计采购额 | 合作以来累计采购额 ≥ 公司年营收的 10% |
| 战略价值 | 有区域独家代理潜力 / 可带动关联品类销售 / 有行业标杆效应 |


## 📊 大客户分级体系（模拟示例）

> ⚠️ 以下数据为模拟示例，请替换为实际客户数据后使用。

| 等级 | 年采购额 | 战略价值 | 服务标准 | 跟进频率 |
| :--- | :--- | :--- | :--- | :--- |
| A（战略级） | ≥ $100,000 | 高 | 专属大客户经理 + 季度高层互访 + 年度客户答谢 | 每月至少 1 次 |
| B（核心级） | $50,000 – $100,000 | 中 | 专属销售对接 + 优先排产 + 半年度高层互访 | 每 2 周至少 1 次 |
| C（潜力级） | $20,000 – $50,000 | 中低 | 标准服务 + 定期关怀 | 每月至少 1 次 |

> 其他非大客户按常规客户维护，频率为每季度 1 次。

## 🔄 客户健康度监控

### 需警惕的异常信号

| 异常信号 | 触发阈值 | 应对动作 |
| :--- | :--- | :--- |
| 采购频率下降 | 连续 2 次采购间隔延长 50% 以上 | 主动联系，询问原因，探查竞品动态 |
| 采购量下降 | 单次采购量低于历史均值的 70% | 了解客户业务变化，判断是否为季节性因素 |
| 关键人变动 | 采购经理/总经理更换 | 尽快建立与新关键人的联系，重塑信任 |
| 付款延迟 | 首次出现逾期 | 温和提醒；如连续 2 次逾期，升级催款流程 |
| 询盘减少 | 连续 60 天无主动询盘 | 主动发送行业资讯或新品信息，创造沟通场景 |
