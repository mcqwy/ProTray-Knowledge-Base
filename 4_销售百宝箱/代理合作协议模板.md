# 代理合作协议模板（Word 转 Markdown 版）

> **用途**：与海外代理签订正式合作协议时使用。
> **更新日期**：2026-09-05

## 📝 使用说明

| 步骤 | 操作 |
| :--- | :--- |
| 1 | 将下方内的内容复制到 Word 文档中 |
| 2 | 填写所有 `[ ]` 中的占位符 |
| 3 | 导出为 PDF 格式 |
| 4 | 使用 DocuSign / HelloSign 进行双方电子签名 |


## 📄 协议完整模板

```
代理合作协议

协议编号：AG-2026-001
签订日期：2026年____月____日

甲方（供货方）：[公司全称]
地址：[详细地址]
联系人：[姓名] │ 电话：[电话] │ 邮箱：[邮箱]

乙方（代理方）：[公司全称]
地址：[详细地址]
联系人：[姓名] │ 电话：[电话] │ 邮箱：[邮箱]

经双方友好协商，就乙方代理甲方产品销售事宜，达成如下协议：

─────────────────────────────────────────────────────────────────
第一条  代理区域与范围
─────────────────────────────────────────────────────────────────
1.1 代理区域：[具体国家/地区]
1.2 代理产品：[具体产品名称及型号]
1.3 代理性质：本协议为【 】独家代理 / 【 】非独家代理

─────────────────────────────────────────────────────────────────
第二条  代理期限
─────────────────────────────────────────────────────────────────
本协议有效期为____年，自2026年____月____日起至20____年____月____日止。
期满前30天双方可协商续签。

─────────────────────────────────────────────────────────────────
第三条  销售目标与佣金
─────────────────────────────────────────────────────────────────
3.1 年度最低销售目标：[XX]美元/年（或[XX]个货柜/年）
3.2 佣金计算方式：【 】按销售额____%  【 】按固定金额____元/单
3.3 佣金支付方式：乙方下单后，甲方支付货款的____%作为佣金
3.4 支付时间：甲方收到客户全款后____个工作日内支付

─────────────────────────────────────────────────────────────────
第四条  甲方权利与义务
─────────────────────────────────────────────────────────────────
4.1 提供符合质量标准的合格产品
4.2 提供产品目录、样品及技术资料
4.3 对乙方推荐的客户给予优先报价权
4.4 保护乙方在代理区域的客户信息，不直接联系乙方客户

─────────────────────────────────────────────────────────────────
第五条  乙方权利与义务
─────────────────────────────────────────────────────────────────
5.1 积极推广甲方产品，完成年度销售目标
5.2 及时向甲方反馈市场需求及竞争对手信息
5.3 不代理与甲方产品有直接竞争关系的同类产品
5.4 未经甲方书面同意，不得将代理权转让

─────────────────────────────────────────────────────────────────
第六条  终止条款
─────────────────────────────────────────────────────────────────
6.1 乙方连续____个季度未完成销售目标的____%，甲方有权终止协议
6.2 任何一方违反协议条款，另一方可书面通知终止协议
6.3 协议终止后，乙方应立即停止使用甲方品牌及资料

─────────────────────────────────────────────────────────────────
第七条  争议解决
─────────────────────────────────────────────────────────────────
因本协议引起的任何争议，双方应首先友好协商解决；协商不成的，
提交甲方所在地有管辖权的人民法院诉讼解决。

─────────────────────────────────────────────────────────────────
第八条  其他
─────────────────────────────────────────────────────────────────
8.1 本协议一式两份，甲乙双方各执一份，具有同等法律效力
8.2 本协议未尽事宜，双方可另行签订补充协议

─────────────────────────────────────────────────────────────────
甲方签字：________________    日期：________________
（盖章）

乙方签字：________________    日期：________________
（盖章）
```
