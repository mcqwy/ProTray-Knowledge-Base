# B2B免费平台操作指南

> **适用平台**：TradeKey、EC21、Go4WorldBusiness等提供免费会员的B2B平台。

## 📝 免费会员能做什么？
- 发布产品（通常限制10-20个）
- 查看部分买家询盘
- 每月可主动联系买家（数量限制）

## 🚀 免费会员运营3个技巧

**技巧1：标题优化**
- 公式：**核心产品词 + 关键属性 + 用途**
- 示例："70g PET Seedling Trays Greenhouse Supplies Gardening Tray"

**技巧2：图片与视频**
- 主图：白底产品图（不低于800x800像素）
- 副图：工厂实拍、包装过程、应用场景
- 视频：30秒产品展示短视频

**技巧3：定期刷新**
- 大部分平台"最近更新"靠前展示
- 每周至少登录刷新1次产品
- 每次刷新后观察是否有询盘增加
