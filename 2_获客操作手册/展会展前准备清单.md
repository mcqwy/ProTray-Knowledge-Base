# 展会展前准备清单（参展商版）

> **适用场景**：广交会、行业专业展等线下展会。

## 📋 展前3个月
- [ ] 确定展位位置和面积
- [ ] 设计展位装修方案
- [ ] 确定参展样品清单
- [ ] 制作新的产品目录/宣传册
- [ ] 培训参展人员（产品知识、礼仪、英语话术）

## 📋 展前1个月
- [ ] 向老客户发送展会邀请函
- [ ] 在社交媒体发布参展预告
- [ ] 准备名片、笔记本、订书机等办公用品
- [ ] 设计展位小礼品（带公司Logo）
- [ ] 预约展会期间的客户见面时间

## 📋 展前1周
- [ ] 确认样品、宣传物料已打包
- [ ] 确认住宿、交通
- [ ] 准备充电宝、转换插头、WiFi热点
- [ ] 再次发送提醒给预约客户

## 📋 展会期间每日必做
- [ ] 晨会：分配当天接待任务
- [ ] 收集每一张名片后立即标注等级（A/B/C）
- [ ] 晚会：汇总当天客户信息，同步到CRM系统
- [ ] 当天展会结束后24小时内给A类客户发送跟进邮件
