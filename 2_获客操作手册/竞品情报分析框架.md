# 竞品获客渠道情报分析框架

> **目标**：不需要窃取商业秘密，通过公开信息推断对手的获客主战场。

## 🔎 分析维度与操作表

| 分析维度 | 去哪里看？ | 能推断出什么？ |
| :--- | :--- | :--- |
| **官网流量来源** | SimilarWeb（免费版） | 对手主要靠SEO还是广告？流量是直接输入还是搜索？ |
| **谷歌广告投放** | 在Google搜索对手品牌名，看有无"广告"标记 | 对手在投哪些关键词？预算是否充足？ |
| **LinkedIn主页** | 看对手员工数、职位分布（销售 vs 市场占比） | 是重销售团队还是重品牌营销？ |
| **招聘网站（BOSS直聘）** | 搜索对手公司招聘岗位（如"SEO专员"、"Facebook投手"） | **洞悉其下一步的获客战略！** |
| **社交媒体活跃度** | 查看其YouTube/TikTok更新频率和内容风格 | 内容营销投入大小和团队风格 |
| **B2B平台店铺** | 在阿里国际站搜索对手，看产品排名、橱窗图 | 主推什么产品？定价策略如何？ |

## 📝 分析报告结论模板
> **竞争对手 [XX公司] 的主要获客来源为：**
> 1. **付费广告**（谷歌广告投放力度大，关键词覆盖 [XX] 个）
> 2. **SaaS拓客系统**（招聘大量销售使用CRM，推测为主动开发模式）
> 3. 对我们启示：**我们应避开其广告锋芒，重点发力TikTok内容营销。**
