# SaaS拓客系统使用操作手册（通用版）

> **涉及系统**：小满（OKKI）、孚盟、网易外贸通等。

## 🚀 核心三步骤

### 第一步：客户挖掘（找客户）
- **操作**：设置产品关键词 + 目标国家 + 行业分类
- **系统动作**：自动抓取海关数据、企业官网、社交账号
- **输出**：生成含公司名、邮箱、电话、决策人LinkedIn的线索列表

### 第二步：自动化营销（触达）
- **操作**：在系统内创建"开发信序列"
- **设置**：第1天发开发信 → 第3天发跟进信（未打开者） → 第7天发优惠诱导
- **系统动作**：自动追踪打开率、点击率，标记高意向客户

### 第三步：客户管理（SCRM）
- **操作**：将沟通记录（邮件、电话、WhatsApp）录入系统
- **系统动作**：生成客户画像，到期自动提醒跟进

## 📊 关键数据看板指标
- **线索转化率**：线索 → 有效询盘的比率（行业平均3%-5%）
- **邮件打开率**：低于20%需优化标题
- **回复率**：低于2%需优化内容或调整目标市场
