## 🔍 25+高级搜索筛选器详解

### 核心筛选组合（B2B外贸必用）

| 筛选维度 | 推荐设置 | 作用 |
| :--- | :--- | :--- |
| **职位关键词** | Purchasing Manager / Procurement / Sourcing / Buyer / Director | 锁定采购决策人 |
| **行业** | 选择目标行业（如Agriculture、Manufacturing） | 精准过滤行业 |
| **公司规模** | 50-500人（中小企业，决策链短） | 避开超大企业，新手易突破 |
| **公司名称** | 输入目标客户公司名 | 精准定位特定客户 |
| **地区** | 选择目标国家/城市 | 聚焦目标市场 |
| **职能级别** | CXO / Director / Manager | 跳过基层员工，直接找决策者 |
| **最近活跃** | 过去30天内有动态 | 确保账号活跃，回复率高 |

### 进阶搜索技巧

**技巧1：排除招聘/HR**
```
NOT (HR OR Recruiter OR "Human Resources")
```

**技巧2：锁定决策人而非采购员**
```
(Title: "Manager" OR Title: "Director" OR Title: "VP") AND NOT (Title: "Assistant")
```

**技巧3：搜索在特定LinkedIn群组中的目标客户**
- 先加入行业群组 → 在群组成员中筛选"职位关键词 + 地区"

## 📧 InMail模板（付费版专属，高回复率）

### 模板1：精准破冰（强个性化）
**主题（自动显示）**：Re: [Company Name]'s [Product] sourcing

```
Hi [First Name],

I've been researching [Company Name] and noticed you're expanding into [specific area] - saw your recent post about [topic].

We're a leading manufacturer of [Product] with [X] years experience. Our latest [feature] might be a good fit for your upcoming projects.

Quick question: do you currently work with any Asian suppliers for [Product]?

Would love to share our catalog and sample policy.

Best,
[Your Name]
[Company]
```

### 模板2：Value-First（先给价值）
```
Hi [First Name],

I recently published a [report/article] on [Topic] that received great feedback from industry peers. Thought you might find it useful:

[链接]

No strings attached - just sharing valuable content. By the way, if you ever need [Product], feel free to reach out.

Cheers,
[Your Name]
```

## ⚠️ 付费版常见误区

| 误区 | 正确做法 |
| :--- | :--- |
| 买了付费版就狂发InMail | 每天发10-15条为宜，发太多容易被举报 |
| 只发InMail不加好友 | 先加好友，通过后再发消息（成功率更高） |
| 不建立"保存搜索" | 保存搜索后，系统每日推送新客户，省去重复搜索时间 |
| 不做客户标签管理 | 用系统标签（如"高意向"、"已联系"、"待跟进"）分类管理 |
