# 外贸独立站建站流程（从0到1）

> **平台选择**：WordPress（灵活） vs Shopify（简单）

## 📋 建站5步法

**第一步：域名与服务器**
- 域名：简短易记，含核心关键词（如 [产品] + [工厂].com）
- 服务器：选择目标市场所在区域的服务器（美国市场选美西服务器）

**第二步：安装与主题**
- WordPress：安装 + 选择外贸专用主题（如Astra、Flatsome）
- Shopify：直接选模板，按年付费

**第三步：核心页面建设**
| 页面 | 必须包含内容 |
| :--- | :--- |
| 首页 | 品牌定位 + 核心产品 + 工厂实力展示 |
| 产品页 | 多角度图片 + 详细参数 + 视频 + 询盘表单 |
| 关于我们 | 工厂实拍 + 团队介绍 + 资质证书 |
| 联系我们 | 表单 + WhatsApp + 地址 + 地图 |

**第四步：SEO基础设置**
- 安装Yoast SEO插件（WordPress）
- 每个页面设置标题标签（Title Tag）和描述标签（Meta Description）
- 提交网站地图到Google Search Console

**第五步：上线与测试**
- 检查所有页面打开速度（谷歌PageSpeed Insights ≥ 70分）
- 测试询盘表单是否正常发送邮件
- 手机端适配检查
