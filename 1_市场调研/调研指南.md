## 🎯 什么时候需要做市场调研？

| 场景 | 调研重点 | 调研深度 |
| :--- | :--- | :--- |
| **进入全新市场**（如首次进入美国市场） | 全部5步 | ⭐⭐⭐⭐⭐ 深度 |
| **现有市场推新品** | 客户需求 + 竞品 | ⭐⭐⭐ 中等 |
| **现有市场提价/降价** | 竞品定价 | ⭐⭐ 轻量 |
| **年度战略复盘** | 市场规模增长 + 客户满意度 | ⭐⭐⭐⭐ 较深 |
| **怀疑客户正在流失** | 竞品动态 + 客户调研 | ⭐⭐ 轻量 |
